# Branding

CrateStack has one mark — three stacked isometric crates in orange — used in two
places with deliberately different treatments. The gallery/app mark carries a dark
rounded-square tile; the `.cstack` file-type icon carries the same crates on a
transparent background. They are the same drawing, not two logos.

## The mark

<Frame caption="The CrateStack app icon — the mark on its tile, as used for the VS Code extension listing.">
  <img src="/images/branding/cratestack-app-icon-256.png" alt="The CrateStack mark: three stacked isometric orange crates on a dark rounded-square tile" width="192" height="192" />
</Frame>

This is the gallery/app mark. It is what the `cratestack-vscode` extension shows
on its Marketplace listing. The `#1E222E` rounded square is part of *this* asset,
not part of the mark in general — see [Usage](#usage).

Every asset on this page is generated from one measured geometry definition, so
the app icon, the logomark and the file icons cannot drift apart. **The SVG is
the master**; every PNG and JPEG below is rendered from it. Prefer the vector
wherever the surface accepts one.

## Colour palette

Sampled from the mark itself; use these values exactly rather than eyeballing a
near match.

| Role                    | Hex       | Notes                                                                 |
|-------------------------|-----------|-----------------------------------------------------------------------|
| Background / tile       | `#1E222E` | The rounded-square plate. Also the extension's `galleryBanner.color`. |
| Crate top face          | `#F7B270` | The lit face of each crate.                                           |
| Crate left / front face | `#E88A3A` | The mid-tone face.                                                    |
| Crate right / shadow    | `#BF6A26` | The shaded face that gives the stack its depth.                       |

## The `.cstack` file icon

The file-type icon is the same three crates redrawn as geometry — so it stays
crisp at the 16×16 an editor's file explorer actually renders — with **no
background plate**. It ships in two theme variants.

The light variant is a **legibility adjustment, not a second palette**: the hue is
unchanged, each value is deepened one step so the pale top face does not wash out
against a near-white explorer background at 16×16.

|------------|--------------|---------------|
| Top        | `#F7B270`    | `#EDA05C`     |
| Left       | `#E88A3A`    | `#D97B2E`     |
| Right      | `#BF6A26`    | `#A85920`     |

<Note>
**JPEG has no transparency.** The logomark JPEGs are flattened onto a named
background, which is why there are two and why each says which. If you need the
mark over anything else, take the PNG or the SVG — do not flatten a JPEG onto a
colour it was not rendered for. There is no JPEG of the file icon for the same
reason: a file icon is transparent by definition.
</Note>

## Usage

- **The dark tile belongs to the gallery/app mark only.** Do not bake `#1E222E`
  into a file icon or an inline mark — a file icon sits on the host's own
  background, so an opaque plate renders as a dark box against every theme that
  is not exactly that navy.
- **File icons and inline usage use a transparent background**, and pick the
  variant that matches the surrounding theme.
- **Do not recolour the crates.** The two variants above are the whole set; a
  third tint is a new mark, not a theme.
- **Do not redraw or restretch the mark.** Scale it uniformly; the isometric
  geometry breaks under non-uniform scaling.

<Note>
Both variants are the canonical `.cstack` file-type asset, and the
`cratestack-vscode` extension registers them as the language icon for `.cstack`
files — see [Editor Tooling](/tooling/editor-tooling). That language-icon
contribution is not in a published extension release yet; the assets themselves
are canonical regardless.
</Note>
